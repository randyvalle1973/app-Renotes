ReNotes es una aplicación móvil desarrollada con Flutter y Dart que permite organizar proyectos, gestionar notas y clasificarlas mediante etiquetas.

El objetivo de la aplicación es ofrecer una herramienta sencilla, intuitiva y organizada para almacenar información y encontrarla rápidamente.

🚀 Funcionalidades

Gestión de proyectos: crear, visualizar, editar y eliminar proyectos.

Gestión de notas: crear, consultar, modificar y eliminar notas dentro de cada proyecto.

Etiquetas: crear, editar y eliminar etiquetas para clasificar las notas.

Autocompletado: sugerencias de etiquetas existentes al escribir en el editor de notas.

Búsqueda global: localizar notas mediante su título o contenido.

Filtros: filtrar notas por proyectos y etiquetas, incluyendo condiciones AND/OR.

Navegación: acceso a las secciones principales mediante una barra de navegación inferior.

Personalización: interfaz adaptable con modo claro y oscuro.

🛠️ Tecnologías utilizadas

Flutter: framework para el desarrollo de la aplicación.

Dart: lenguaje de programación.

Material Design: componentes visuales para la interfaz.

ChangeNotifier: gestión del estado de la aplicación.

📁 Organización del proyecto

El código está organizado en diferentes carpetas:

models/: modelos de proyectos, notas y etiquetas.

screens/: pantallas de la aplicación.

widgets/: componentes reutilizables.

state/: gestión del estado y operaciones de la aplicación.

data/: datos iniciales de ejemplo.

theme/: configuración de los temas visuales.

▶️ Ejecución

Tener instalado Flutter y configurado el entorno de desarrollo.

Clonar o descargar el repositorio.

Abrir el proyecto en Visual Studio Code.

Ejecutar los siguientes comandos:

flutter pub get
flutter run

📌 Consideraciones

La aplicación utiliza almacenamiento temporal en memoria, por lo que los cambios realizados durante su ejecución no se conservan al reiniciarla.

Incluye proyectos, notas y etiquetas de ejemplo para facilitar la demostración de sus funcionalidades.

🎓 Propósito

Proyecto académico desarrollado para poner en práctica conceptos de programación móvil con Flutter, incluyendo navegación entre pantallas, formularios, gestión del estado, componentes reutilizables y organización del código.
